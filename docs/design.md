# 设计与边界

核心职责只有三层：

- 调用方负责输入拆页、每页启动一个 Codex、取消和最终按顺序合并。
- Codex 负责观察页面、选择对象表达、调用 Skill 工具、查看 PowerPoint
  真实渲染并修复可见问题。
- Skill 负责确定性的 OCR 提示、源像素素材、可编辑对象构建、字体适配、
  PowerPoint 渲染、比较、PPTX 回读和多页合并。

重建不是重新设计。源图中的文字、数字、信息分组、相对几何和视觉层级
是权威。普通信息内容必须可编辑；只有本质上是位图或不适合拆解的局部
视觉元素可以作为图片对象。禁止整页或接近整页的截图覆盖。

共享 Builder 使用源像素坐标，解析本机实际字体，支持富文本 runs、原生
表格、原生连接线、箭头、常用形状和紧凑图片。页面专用 Python 脚本应
使用 `editppt.authoring.SlideManifest`，不得重新实现 OOXML、字体适配、
表格或连接线。

PowerPoint 真实渲染是 Codex 写 `ready` 前的自检，不是调用方的第二套
质量状态机。调用方只消费成功退出后的 `page.pptx` 和 `result.json`。
