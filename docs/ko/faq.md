# 자주 묻는 질문

## 객체 수만 확인하면 왜 부족한가요?

객체가 있어도 줄바꿈, 겹침, 글꼴 대체, 위치 오류가 남을 수 있으므로 Microsoft PowerPoint 실제 렌더를 봐야 합니다.

## PowerPoint 렌더가 실패하면 어떻게 하나요?

`ready`를 작성하지 말고 LibreOffice나 전체 스크린샷으로 대체하지 않습니다. `.editppt/render/` 증거를 보존하고 권한, 대화상자 또는 파일 문제를 해결합니다. renderer는 고유한 대상 사본만 열고 닫으며 추가 canary를 만들지 않습니다.

## 이미지 객체를 사용할 수 있나요?

로고, 사진, 지도, 스크린샷과 복잡한 일러스트의 작은 원본 픽셀 자산에는 사용할 수 있습니다. 제목, 본문, 표, 타임라인과 일반 도표는 이미지로 만들지 않습니다.
