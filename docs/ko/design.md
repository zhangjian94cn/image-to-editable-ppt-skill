# 설계와 경계

- 호출자는 입력 분리, 페이지별 Codex 실행, 취소와 순서 기반 조립을 담당합니다.
- Codex는 시각 판단, 객체 선택, 도구 선택, 실제 렌더 확인과 수정 작업을 담당합니다.
- Skill은 OCR 힌트, 원본 픽셀 자산, 편집 객체 생성, 설치 글꼴 맞춤, PowerPoint 렌더, 비교, PPTX 판독과 조립을 담당합니다.

재구성은 재디자인이 아닙니다. 원본 문구, 데이터, 그룹, 상대 위치와 계층이 기준입니다. 페이지 전용 스크립트는 `editppt.authoring.SlideManifest`를 사용하며 OOXML, 글꼴 맞춤, 표 또는 연결선을 다시 구현하지 않습니다.
