# Example prompts

## One page

```text
Use $image-to-editable-ppt to rebuild source.png as one object-level editable
PPTX. Source wording, data, groups, and relative geometry are authoritative.
Use native objects for ordinary content and only compact local images for
logos, photos, screenshots, or complex illustrations. Render and view the
exact page.pptx in Microsoft PowerPoint before writing result.json.
```

## Multiple pages

```text
Use $image-to-editable-ppt for this PDF. Run one local Codex task per page,
then assemble the successful page.pptx files in source order. Deliver only the
editable deck.
```
